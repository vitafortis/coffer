Self-hosted secrets for a small team

Passwords, API keys, key pairs and certificates, by project and environment, encrypted on your own server. Use them from the browser, the command line or a browser extension, and share one with a link that works once.

Install with Docker Read the docs 
# fetch what you need, where you need it
coffer use billing-api prod
coffer get DATABASE_URL
coffer gen password -l 32 --save ADMIN_PASSWORD
coffer gen cert --cn api.internal --days 90 --issuer infra/prod/ca/ROOT_CA --save TLS
coffer share DATABASE_URL --expires 1h   # → https://coffer.example.com/s/…#…

Stores and shares secrets. Doesn't push them anywhere.

No syncing into clouds, CI or Kubernetes. Whatever needs a secret fetches it with a token, or a person copies it, and every read is in the activity log with who did it.

Projects and environments

Every environment has its own value for each secret, in folders. Compare shows what's missing from production, and copies it across in one click.

Keys and certificates

Generate passwords, keys, SSH key pairs and X.509 certificates, including ones signed by a CA you keep in Coffer. Certificates about to expire show on the home page.

One-time links

Hand a secret to someone without an account. The key lives only in the link's #fragment, so not even the server can open it, and it's wiped after it's read.

Browser extension

The secrets for the site you're on come first, ready to fill. Search everything, and fill new-password fields from the right-click menu.

History and activity

The last 30 values of every secret, with who set each one. Restore any of them in one click. Every read, change, share and sign-in is logged.

Tokens for people and scripts

Personal API tokens, optionally read-only and expiring. Only a hash is stored, and a token can't open the web app or make more tokens.

Encrypted at rest, and you hold the key

Values are encrypted with AES-256-GCM under a master key that never leaves your server, each one bound to its own row. Lists and search never decrypt.

Up in a minute

Installation guide 
mkdir coffer && cd coffer
curl -fsSLO https://raw.githubusercontent.com/vitafortis/coffer/main/compose.yaml
docker compose up -d
# then open http://<your-host>:3070
